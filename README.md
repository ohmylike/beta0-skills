# beta0-skills

[β0（ベータゼロ）](https://trybeta0.com)を、Claude などの AI エージェントから使うためのスキル集です。

β0 は、公開前の LP、商品ページ、サービスサイト、記事の下書きなどを、日本の人口統計にもとづく架空の消費者（合成ペルソナ）に1人ずつ読ませて、どこで読むのをやめるか、何が足りないかを、引用つきで返すサービスです。

## 入れ方

1. β0 の MCP サーバーを、お使いの AI につなぎます。接続先は `https://mcp.trybeta0.com/mcp` です。つなぎ方は https://trybeta0.com/mcp/ にあります。
2. スキルを入れます。

```sh
npx skills add ohmylike/beta0-skills
```

## 入っているスキル

| スキル | 内容 |
| --- | --- |
| [beta0](skills/beta0/SKILL.md) | ページや文章を読ませる、結果を読む（JSON も）、直して同じ顔ぶれで比べる、別の記事を同じ顔ぶれに読ませる、の流れと、結果を伝えるときの注意 |

## 使い方の例

- 「この LP を、子育て中の母親10人に読ませて」
- 「さっきの結果をもとに、最初の画面の文を直す案を出して」
- 「直したので、同じ人にもう一度読ませて比べて」
- 「この記事の下書き（Markdown）を、投資を始めたばかりの人10人に読ませて」
- 「昨日と同じ10人に、今日の記事も読ませて」
- 「同じ条件で、まだ読んでいない別の10人にも読ませて」

## ご注意

結果は、AI が演じた架空の人物の回答による推定です。実在の人への調査ではなく、人数は実際の割合を表しません。
